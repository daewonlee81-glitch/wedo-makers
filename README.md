# 위두 메이커스 — WeDo 2.0 워드블럭 + Python

**5개 언어 지원: 한국어 · English · 日本語 · 简体中文 · Español** (상단에서 선택, 주소 끝에 `#en` `#ja` `#zh` `#es` 를 붙여 바로 열 수도 있습니다)

LEGO WeDo 2.0 허브를 웹브라우저에서 블록으로 코딩하고, 같은 프로그램을 Python 코드로 바로 확인하는 웹 서비스입니다.
설치할 것이 없는 정적 웹페이지(파일 1개)라서 어떤 웹호스팅에도 그대로 올릴 수 있습니다.

## 구성 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 웹앱 전체 (Blockly 포함, 외부 의존성 없음 · 약 1.5MB) |
| `wedo2.py` | 생성된 Python 코드를 PC에서 실행하는 라이브러리 (bleak 사용) |
| `vendor/tasks-vision/` | AI 카메라용 MediaPipe 라이브러리 (Apache 2.0) |
| `models/` | AI 모델: 스켈레톤(pose_landmarker_lite) · 손 모양(gesture_recognizer) · 사물(efficientdet_lite0) · 학습용 특징 추출(mobilenet_v3_small) |

## 배포 방법
Web Bluetooth는 **https** 주소나 `http://localhost` 에서만 동작합니다.

- **GitHub Pages**: 저장소에 `index.html`, `wedo2.py` 를 올리고 Settings → Pages 를 켜면 `https://아이디.github.io/저장소/` 로 서비스됩니다.
- **Netlify / Cloudflare Pages**: 폴더를 끌어다 놓기만 하면 됩니다.
- **로컬 테스트**: 폴더에서 `python -m http.server 8000` → Chrome에서 `http://localhost:8000`

지원 브라우저: PC·크롬북의 Chrome / Edge (Windows, macOS, ChromeOS, Android Chrome). iPhone·iPad Safari는 Web Bluetooth를 지원하지 않습니다.

## 기능
- **워드블럭**: 이벤트(실행·허브 버튼·키보드·거리·기울기), 모터(켜기/끄기/n초/파워/방향), 불빛(색·RGB), 소리(음계·Hz), 센서, 제어, 연산, 변수(한글 이름 가능), 콘솔 출력
- **변수에 숫자 넣기**: 변수 분류에 `변수를 [0]로 설정`, `변수를 [1]만큼 바꾸기`, `변수를 [거리 센서 값]로 설정` 블록이 숫자 칸과 함께 나옵니다
- **PC 키보드 신호**: `키보드 [키] 키를 누를 때`(이벤트), `키보드 [키] 키가 눌렸는가?`(센서). 스페이스·엔터·화살표·A~Z·0~9, 한/영 상태와 관계없이 인식. 실행 중에는 키가 페이지 스크롤이나 블록 삭제에 쓰이지 않도록 막습니다
- **Python 실시간 변환**: 블록을 바꿀 때마다 오른쪽에 Python 코드가 갱신됩니다. 복사 · `.py` 저장 지원
- **허브 연결**: Web Bluetooth로 WeDo 2.0 허브(LPF2 Smart Hub 2 I/O)에 직접 연결, 포트 1·2의 모터·거리·기울기 센서 자동 인식, 배터리 표시. 연결되면 허브 LED가 **파랑**으로 켜지고, 프로그램이 끝나거나 정지하면 다시 파랑으로 돌아옵니다
- **가상 허브**: 허브가 없어도 실행됩니다. 거리 슬라이더, 기울기 패드, 허브 버튼으로 센서를 흉내 내고 모터·불빛·소리 상태를 화면에서 확인합니다
- **실행 표시**: 실행 중인 블록이 강조되고, 여러 이벤트 스크립트가 동시에 실행됩니다
- **반복 속도**: 반복 블록은 Scratch처럼 한 바퀴에 1/30초 — `속도를 1만큼 바꾸기`를 반복하면 모터가 점점 빨라집니다
- **변수 모니터**: 블록 화면 오른쪽 위에 변수 값이 실시간으로 표시됩니다(접기 가능)
- **블록 가독성**: 흰 글씨 블록은 명암 대비 4.5:1 이상의 색, 밝은 블록(이벤트·제어)은 진한 글씨, 굵은 13.5px 글꼴
- **창 크기 조절**: 블록 화면과 오른쪽 패널 사이(좌우), Python 코드와 허브·콘솔 사이(위아래)를 끌어서 조절. 두 번 클릭하면 원래대로
- **AI 카메라**: PC 카메라로 인식한 값을 블록에서 바로 씁니다. 블록을 쓰고 실행하면 카메라가 자동으로 켜지고, 블록 화면 오른쪽 아래 창에 스켈레톤·손·사물·색깔 인식 결과가 그려집니다. 영상은 PC 밖으로 전송되지 않습니다
  - 🦴 스켈레톤: `사람이 보이는가?`, `[오른팔] 을 들었는가?`, `[오른손목] 의 [x] 위치`, `[왼팔] 팔꿈치 각도`, `몸(어깨) 기울기`
  - ✋ 손 모양: `손이 보이는가?`, `손 모양이 [👍 엄지 위로] 인가?` (주먹·보자기·검지·엄지 위/아래·브이·사랑해), `펼친 손가락 수`, `손의 [x/y] 위치`
  - 📦 사물: `[컵] 이 보이는가?`, `[컵] 의 [x] 위치`, `보이는 [사람] 의 수` (사람·컵·병·공·휴대폰·책 등 15종)
  - 🎨 색깔: `[빨강] 색이 보이는가?`, `[빨강] 색의 [x / y / 크기]` (빨강·초록·파랑·노랑)
  - 이벤트 `‹조건› 이 될 때` — 예: `오른팔을 들었는가?` 가 참이 되는 순간 실행
  - 좌표: 거울 화면 기준 x 0(왼쪽)~100(오른쪽), y 0(아래)~100(위). 안 보이면 -1
- **AI 학습 (사물 학습 · 색 학습)**: 카메라 창의 **🧠 AI 학습하기** 또는 AI 카메라 분류의 버튼으로 엽니다
  - **사물 학습**: 클래스(예: 빨간 컵 / 파란 공 / 배경)마다 `누르고 있으면 촬영`으로 사진을 모으고 `학습시키기`. 확신도 막대로 바로 시험. 블록 `학습한 사물이 [빨간 컵] 인가?`, `학습한 사물 이름`, `[빨간 컵] 확신도 (%)`
  - **색 학습**: 화면 가운데 네모에 색 물건을 대고 `가운데 색 학습` → 이름·허용 범위 정하기. 색 블록 목록에 `★ 내 색` 으로 나타남
  - **학습 방법 안내** 탭: AI가 배우는 원리(사진 → 숫자 1,024개 → 가장 비슷한 학습 사진 7장으로 판단), 사물 학습 5단계·색 학습 4단계, 잘 배우게 하는 요령, 예제 아이디어 (5개 언어)
  - 학습 내용은 프로젝트 파일과 함께 저장되고, `Python용 학습 파일 저장`으로 받은 .json 을 Python에서 `load_learning('파일.json')` 으로 그대로 씁니다
- **오류 신고**: 상단 깃발 버튼 또는 콘솔의 오류 줄에서 robot-league@naver.com 으로 진단 정보와 함께 보낼 수 있습니다
- **저장**: 브라우저에 자동 저장, `.wedo.json` 파일로 내보내기/열기
- 단축키: `Ctrl+Enter` 실행, `Esc` 정지

## 생성된 Python 코드 실행 (PC)
```bash
pip install bleak
pip install pynput        # 키보드 블록을 쓴 경우에만
pip install mediapipe opencv-python   # AI 카메라 블록을 쓴 경우에만 (처음 실행 때 모델 자동 다운로드, Q 로 카메라 창 닫기)
# 학습한 사물을 쓴 경우: 'Python용 학습 파일 저장'으로 받은 *_learning.json 을 .py 옆에 두기
python 내프로젝트.py      # 같은 폴더에 wedo2.py 가 있어야 합니다
```
macOS에서 키보드 블록을 쓰려면 터미널에 '손쉬운 사용(입력 모니터링)' 권한이 필요합니다.

## 개발 (소스에서 다시 빌드)
`index.html` 은 `src/` 의 소스와 Blockly를 한 파일로 합친 결과물입니다. 소스를 고친 뒤:
```bash
npm install          # Blockly 설치
python3 build.py     # index.html, wedo2.py 다시 생성
```
| 경로 | 내용 |
|---|---|
| `src/index.html` | 화면 구조 · 스타일 |
| `src/i18n.js` | 5개 언어 번역표 (화면·블록·도움말) |
| `src/blocks.js` | 워드블럭 정의 + JavaScript/Python 코드 생성기 |
| `src/camera.js` | AI 카메라: 스켈레톤·손 모양·사물·색깔 인식, 사물 학습(특징 벡터 + 최근접 이웃)·색 학습, 화면 그리기 |
| `src/hub.js` | WeDo 2.0 Web Bluetooth 드라이버, 가상 허브, 실행 런타임 |
| `src/app.js` | 툴박스, 저장, Python 보기, 키보드·변수 모니터 등 UI |
| `src/wedo2.py` | PC용 Python 라이브러리 원본 |
| `assets/` | 로고 · 파비콘 |
| `models/` | AI 모델 원본 (빌드 시 그대로 사용) |
